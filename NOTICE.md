## SAM 2

`scenes/sam2_video_predictor.py` is adapted from the SAM 2 implementation in
ailia-models, reference commit `35a19ec2ed4db1bfa6bcb10334f93fa74b471b17`.
The tracking algorithm originates from Meta's Segment Anything 2.
Local changes support 512-pixel feature grids, split/padded memory inputs,
the shared model-weight directory and formatting. See `licenses/SAM2_LICENSE`
(Apache License 2.0). Original project: https://github.com/facebookresearch/sam2

The bundled ONNX models and downloaded auxiliary models and weights derive from
SAM 2.1 Tiny (Hiera Tiny), distributed through ailia-models:
https://storage.googleapis.com/ailia-models/segment-anything-2.1/
The image encoder and Memory Attention are adapted to 512 pixels and INT8,
with QDQ MatMuls lowered offline to standard ONNX MatMulInteger/Cast/Mul.
The encoder includes shape-only adaptations for NXP ORT timing; its Neutron
EP outputs are not accuracy-qualified. Prompt, mask decoder and memory encoder are adapted to 512 pixels.
The remaining MLP and temporal projection are unmodified model exports.
These are demo conversions, not official Meta or NXP model releases.

## Grounding DINO

The Grounding DINO Swin-T model derives from the public ailia-models export:
https://github.com/ailia-ai/ailia-models/tree/master/object_detection/groundingdino
Original project: https://github.com/IDEA-Research/GroundingDINO
See `licenses/GROUNDING_DINO_LICENSE` (Apache License 2.0).
The conversion uses COCO val2017 Min/Max calibration, integer fixed-weight
MatMuls, and a standard-ONNX rearrangement of multi-scale deformable attention.
This is a demo conversion, not an official upstream model release.

`models/grounding_tokenizer/vocab.txt` is the BERT-base-uncased vocabulary
distributed with the ailia-models Grounding DINO example.
Original BERT project: https://github.com/google-research/bert (Apache 2.0).

## Depth Anything V2

The Metric Depth Hypersim Small model derives from the ailia-models ONNX export:
https://github.com/ailia-ai/ailia-models/tree/master/depth_estimation/depth_anything_v2
Original model: https://huggingface.co/depth-anything/Depth-Anything-V2-Metric-Hypersim-Small
See `licenses/DEPTH_ANYTHING_LICENSE` (Apache License 2.0).
The demo conversion fixes the input to 518 pixels and uses COCO val2017
calibration for fixed-weight INT8 MatMuls. Dynamic MatMuls use explicit ONNX
DynamicQuantizeLinear and MatMulInteger nodes. This is a modified demo model,
not an upstream release.

## YOLOX

The YOLOX-S model derives from the ailia-models ONNX export:

Original project: https://github.com/Megvii-BaseDetection/YOLOX
See `licenses/YOLOX_LICENSE` (Apache License 2.0).
